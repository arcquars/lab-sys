# Frontend

- Vistas Blade en `resources/views/`, layouts en `resources/views/layouts/` (Light Bootstrap Dashboard).
- Bootstrap 4 + jQuery (ver skills `bootstrap` y `jquery`).
- No introducir frameworks JS modernos.
- Reutilizar includes/componentes Blade cuando sea posible.
- Assets compilados con laravel-mix 4: `npm run dev` / `npm run prod`.
