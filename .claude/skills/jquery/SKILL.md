# jQuery

- Usar jQuery. No reemplazar por Vue ni React (Vue esta en package.json pero no se usa).
- Mantener compatibilidad con los plugins existentes (DataTables, etc.).
- CRUD via `$.post` hacia metodos `ajax*` de los controladores; incluir el token CSRF.
